# Moje Radio — PWA

## Publikacja przez GitHub Pages
1. Utwórz na GitHubie repozytorium `moje-radio-pwa`.
2. Wgraj zawartość tego katalogu: `index.html`, `manifest.webmanifest`, `sw.js`, `icons/` i `README.md`.
3. Otwórz **Settings → Pages**.
4. W **Build and deployment** wybierz **Deploy from a branch**, gałąź `main` i folder `/ (root)`, a następnie zapisz.
5. Po publikacji otwórz adres GitHub Pages na telefonie i wybierz w Chrome menu ⋮ → **Zainstaluj aplikację** lub **Dodaj do ekranu głównego**.

## Ważne
- PWA działa przez HTTPS, więc GitHub Pages jest odpowiednim miejscem do hostowania.
- Plik HTML i podstawowe zasoby są buforowane, ale transmisje, wyszukiwanie stacji i pogoda wymagają internetu.
- To pierwsza wersja instalacyjna; trzeba jeszcze przetestować odtwarzanie stacji na telefonie i Android TV.
